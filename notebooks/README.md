# 노트북 실행 안내

`seoul_bike_analysis.ipynb`는 첨부된 팀 통합 Colab 노트북의 파일명만 변경한 원본입니다. 기존 실행 출력과 분석 코드가 보존되어 있습니다.

## 권장 환경과 순서

Google Colab에서 열어 실행합니다. 노트북은 `google.colab.drive`로 Drive를 연결하며, Linux 한글 폰트 설치 셀을 포함합니다. 일반 로컬 Python에서 그대로 실행하는 환경은 아닙니다.

1. [데이터 안내](../data/README.md)에 따라 2025년 월별 원본 파일을 준비합니다.
2. 환경 설정 셀을 실행하고 `BASE_DIR`, `DATA_DIR`, `OUTPUT_DIR`를 변경합니다.
3. 필요하면 단일 월 EDA로 데이터 형식과 품질을 확인합니다.
4. 전체 월 일괄 처리로 월별 집계 파일을 생성합니다.
5. 연간 통합 분석을 실행한 뒤 거리·요일·시간대별 추가 분석을 진행합니다.

추가 분석 일부는 별도 연간 집계 파일 경로를 직접 참조합니다. 해당 경로를 본인의 생성 파일로 맞춰야 하며, 생성되지 않은 입력을 자동으로 확보하는 기능은 없습니다. 월별 파일은 전체를 메모리에 읽으므로 충분한 메모리와 실행 시간이 필요합니다.

`requirements.txt`는 코드에서 확인된 주요 라이브러리 목록입니다. 기존 실행 환경의 버전 정보가 없어 버전은 고정하지 않았습니다. Colab의 Drive 모듈과 한글 폰트는 노트북의 환경 설정을 따릅니다.

## 검증 범위

파일 형식, 주요 전처리·파생변수 코드, 저장된 출력과 보고서 수치를 대조했습니다. 원본 CSV가 없어 전체 실행이나 현재 Colab 환경에서의 결과 일치는 검증하지 않았습니다. 알려진 차이는 [검토 메모](../docs/source_review.md)에 정리했습니다.
