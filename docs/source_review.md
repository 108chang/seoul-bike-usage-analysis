# 원본 자료 대조 메모

포트폴리오 편집 과정에서 보고서, 발표자료, 통합 Colab 노트북을 대조했습니다. 원본 문서와 코드는 변경하지 않았습니다.

| 항목 | 확인한 내용 | README 반영 기준 |
| --- | --- | --- |
| 개인 기여 | 보고서 표지에서 이창준은 ‘탐색 / 문제정의’ | 세부 개인 작업이나 코드 저작 여부를 추정하지 않음 |
| 대여이력 기간 | 보고서 데이터 표는 2025년, 노트북은 2501–2512 처리. 발표자료 28쪽에는 2026.12.31까지 표기 | 2025년 분석으로 기재 |
| 정제 건수 | 보고서 표 II-3, 발표자료 7쪽, 노트북 처리 로그 일치 | 37,372,654 → 33,664,470건 |
| 리뷰 기간 | 보고서 소개 표는 2025.06.01–2026.06.01. 한계 본문은 2025.06.01 기준 최근 1년으로 표기 | 표의 기간을 출처와 함께 제시하되 수집 로그 확인 필요 명시 |
| 거리 경계 | 코드의 `pd.cut`은 기본 `right=True`. 보고서의 3km 미만·5km 이상 등 표현과 경계값 차이 | 원본 구간명 보존, 상한 포함 설명. 단거리 90%를 정확한 검증 수치로 재인용하지 않음 |
| 나이 | 코드에서 `2025 - 생년` | 만 나이로 표현하지 않음 |
| 요일 일수 | 보고서 예시는 월요일 53일. 노트북 달력 출력은 수요일 53일, 나머지 52일 | 실제 달력 기준. 평일 261일·주말 104일 |
| 월별 추이 | 노트북 초기 설명에는 6·7월 최고, 최종 보고서는 6·9월 증가·7월 감소 | 최종 보고서 해석임을 명시. 초기 설명과 차이 공개 |
| 기온 민감도 | 집단별 절대 건수 변화폭을 비교 | 집단 규모와 외부 요인을 통제한 인과관계로 표현하지 않음 |
| 이용 목적 | 시간·요일·거리로 목적 추정 | 출퇴근·여가는 간접 해석임을 명시 |
| 실행 범위 | 기존 Drive 경로와 월별·연간 집계 파일에 의존 | 원자료 없이 전체 실행을 검증했다고 표현하지 않음 |

README의 그림은 노트북의 저장된 출력에서 가져왔습니다. 셀 번호를 1부터 셌을 때 연령대 차트는 54번째 셀, 평일·주말 하루 평균 차트는 64번째 셀, 2030세대 요일별 거리 히트맵은 118번째 셀입니다.

원본 데이터와 리뷰·기온 파일은 첨부되지 않아 재계산하지 않았습니다. 후속 작업에서는 구간 정의와 설명을 통일한 뒤 전체 실행하여 결과와 문서의 일치를 확인하는 것이 좋습니다.
