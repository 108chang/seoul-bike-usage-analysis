# 데이터 출처 및 공개 범위

## 주요 출처

- [서울열린데이터광장](https://data.seoul.go.kr/): ‘서울시 공공자전거 따릉이 대여이력 정보’의 2025년 1–12월 파일. 상세 데이터셋의 최신 주소와 제공 조건은 포털에서 제목으로 검색하여 확인해 주세요.
- [기상자료개방포털](https://data.kma.go.kr/): 보고서에서 사용한 서울 ASOS 108 지점의 2025년 기온 자료.
- App Store·Google Play의 ‘서울자전거 따릉이’ 리뷰: 팀 보고서의 서비스 불편 요인 해석에 사용한 보조 자료.

분석 단위는 개별 대여 건이며, 고유 이용자 단위가 아닙니다. 주 분석 변수는 대여·반납일시, 이용시간(분), 이용거리(M), 생년입니다.

## 원본 파일을 포함하지 않은 이유

원본 대여이력은 37,372,654건으로 저장소에서 관리하기에 큰 규모입니다. 대용량 원본은 제공 포털에서 직접 확보하도록 하고, 이 저장소에는 분석 방법과 팀 산출물을 제공합니다. 따라서 원자료의 별도 재배포도 하지 않습니다. 이는 공개된 공공데이터 자체가 비공개라는 의미는 아닙니다.

원본 CSV, 월별 집계 CSV, 리뷰 본문·작성자 정보, 기온 원자료는 포함하지 않았습니다. 리뷰의 별도 공개·재배포 조건은 확인되지 않았습니다. 노트북에 저장된 집계 통계와 그래프는 포함합니다.

## 재현용 데이터 준비

1. 포털에서 2025년 12개월의 대여이력을 확보하고 이용 조건과 컬럼 구성을 확인합니다.
2. Colab의 개인 Drive에 데이터를 배치하고 노트북의 `BASE_DIR`, `DATA_DIR`, `OUTPUT_DIR`를 본인의 경로로 변경합니다.
3. 코드가 월별 파일명을 `_2501.csv` – `_2512.csv`로 찾으므로 파일명을 확인합니다. 코드의 인코딩은 `cp949`, 결측 표기는 `\\N`입니다.
4. 환경 설정 후 전체 월 일괄 처리로 `집계_기본_2501.csv` – `집계_기본_2512.csv`를 생성합니다.
5. 연간 통합 분석과 추가 교차 분석을 실행합니다. 추가 분석에서 참조하는 연간 파일 경로도 확인합니다.

원본 데이터를 제공받지 않아 모든 셀의 연속 실행과 동일 결과 재현은 검증하지 않았습니다. 소스 제공본의 버전이나 추후 정정에 따라 건수가 달라질 수 있습니다.
